# 🍽️ Recipe Sharing Website

The **Recipe Sharing Website** is a dynamic and user-friendly platform designed to make **sharing, exploring, and managing recipes** simple and enjoyable.  

This website provides an intuitive interface where users can:  
- View detailed recipes with **images, ingredients, preparation steps, and cooking times**  
- Explore **popular categories** of dishes  
- Learn more **about the website and its purpose**  
- Add, edit, or delete recipes through the **backend system**

---

## 🏠 **Home Page**
Users can explore recipes at a glance with an attractive homepage layout, featuring quick access to popular dishes and categories.

## 🍴 **Popular Categories**
Here you can explore different food categories through a **horizontal scroll bar**.  
Users can scroll to view various recipe types — for example, **Breakfast, Lunch, Snacks, Desserts**, and more.  
When a user selects a category, recipes related to that category are **displayed dynamically** below.  

![Popular Categories](https://github.com/MahparaEhsan37/Recipe-Sharing-Webiste/raw/07ccfbfeb3f3d1ba96ec8f4baf0f51df0c42f1b3/recipeSharing2.jpeg)

## 📖 **Detailed Recipe Page**
On the **Detail Recipe** page, users can view **complete recipe information**, including ingredients, step-by-step preparation methods, and cooking instructions.  
If a user likes the recipe, they can **share it with family and friends**.
